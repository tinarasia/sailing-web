# sailing-web

Jekyll blog for S/V Tinarasia ("in no hurry to be anywhere. ever.").

## Working with `_posts/`

Never overwrite a post the site owner has edited by hand. This matters
most for the trip logbook posts (`_posts/2025-*.md`, categorized "Spring
2025" and onward), which are machine-generated by the
`sailing-trip-logbook` skill from GPX track data — but the rule applies to
any post.

The logbook posts are protected automatically: `_posts/.sailing-trip-logbook-manifest.json`
records a hash of each post's content as of when the skill's
`write_posts.py` last wrote it. If you're regenerating posts with that
script, it already checks this and skips anything hand-edited since — you
don't need to check manually before running it. But if you're editing
`_posts/` some other way (a manual find-and-replace, a different script,
etc.), that manifest won't protect you — check with the user first, or at
least diff against git history, before bulk-touching files in there.
